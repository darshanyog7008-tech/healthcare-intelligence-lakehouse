# Data Dictionary

The project works with FHIR/Synthea clinical resources and derives curated Silver entities plus Gold Patient 360 analytics.

Major resource/entity families represented in the notebooks include:

- Patient
- Encounter
- Condition
- Observation
- Procedure
- MedicationRequest
- DiagnosticReport
- Immunization

The exact column definitions are intentionally kept close to the transformation notebooks so the source-to-target logic remains auditable.
